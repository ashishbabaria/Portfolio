## Featured project

### [Sales Growth Between Dates](./01-data-viz/visuals-and-charts/sales-growth-between-dates)

An interactive "growth between two dates" visual built on **one native Power BI line
chart** — no custom visual, no SVG, no HTML. Drag a slider and the highlighted period,
endpoint markers, duration, and growth % all recalculate together. Most of the DAX
isn't calculation at all — it's *stagecraft*.
